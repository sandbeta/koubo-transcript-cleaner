# 稿纸台 · 口播文字稿整理工具 新 UI 设计系统

> 这份是**结构与排版**的设计系统（布局优先级、令牌语义、字号行宽、命中区、无障碍），仍然有效。
> 视觉皮肤换过三代：稿纸台 → 魔法像素 → 星露谷，现在只有星露谷，且已并入产品本体。
> 看皮肤怎么改、门禁跑什么：`README-皮肤.md`。

设计方向来自 `ui-ux-pro-max` 的实检索结果，再按本产品的约束做了有记录的改写。
所有对比度数字由 `node _tokens.mjs` 按 WCAG 相对亮度公式实算，不是估的。

## 1. 为什么是「稿纸台」而不是「后台面板」

现在的界面是**两块等宽栏 + 一串权重相同的小卡片**。它把 5 个阶段（定标准 → 预清洗 → 逐句核对 → 交给大模型 → 归档战绩）平铺在同一屏里，用户每天打开先要在 20 多个区块里重新找一遍"我上次做到哪"。

这个产品真正的主角只有一个东西：**那句被删掉的话**。所以新 UI 的判据是——

> 打开页面 1 秒内，眼睛应该落在稿纸上，而不是落在设置区。

三站式布局因此展开：

| 区域 | 职责 | 宽度 | 随步骤变化 |
|---|---|---|---|
| 左轨 Rail | 5 步进度与入口，配置收进抽屉 | 232px（可折到 56px） | 当前步高亮 + 计数 |
| 中栏 稿纸 | 文稿本体、句级 diff、内联放回 | 弹性，正文行宽锁定 38 字 | 内容随步骤切换 |
| 右栏 检视器 | 只放「当前步骤需要的判断」 | 384px | 报告/风险/零件/素材/成片 |

中栏正文**锁定 38 个汉字**（`max-width: 38em`，18px 字号下约 684px）。中文长行比英文更容易串行，38 字是读稿和扫句之间的折中；1024 以下降到 34 字，768 以下整页单栏、右栏下移成抽屉。

## 2. 与检索结果的三处改写（附理由）

`--design-system` 命中的是 **Minimalism & Swiss Style** + 青绿主色 + `Noto Serif TC / Noto Sans TC`。三点必须改：

1. **不能引网络字体。** 产品对用户的承诺是"页面不发起任何网络请求"，Google Fonts 的 `@import` 直接破坏这条承诺。改用系统已装的中文衬线/黑体栈（见 §4），并给出无衬线兜底。
2. **`#0D9488` 不能当按钮底色。** 白字压在上面只有 **3.74:1**，AA 不过。主色降一档到 **`#0F766E`**（白字 **5.47:1**），`#0D9488` 降级为"仅图形/大字"用途。
3. **返回的 `Product Demo + Features` 落地页版式不适用**（工具不是营销页），弃用；只保留它的媒体无障碍条款（不自动播放、reduced-motion 下给静态终态）。

另外补进两条检索里更贴合本产品的风格：**Editorial Grid / Magazine**（报纸灰底 + 衬线正文 + 明确印刷层级）和 **E-Ink / Paper**（阅读优先、暗色模式不推荐做主档）。

## 3. 色板（三层令牌）

### primitive

```css
/* 纸与墨 */
--p-paper:   #FFFFFF;  /* 稿纸 */
--p-page:    #F5F4F0;  /* 报纸灰页面底 */
--p-panel:   #FBFAF7;  /* 次级面板，比页面略亮 */
--p-ink-900: #1A1D21; /* 15.37:1 on page */
--p-ink-700: #20242A; /* 15.59:1 on paper —— 稿纸正文 */
--p-ink-600: #4A5157; /*  7.32:1 on page —— UI 次级 */
--p-ink-500: #5E666D; /*  5.30:1 on page —— 弱化说明（下限，不许再浅） */

/* 动作青 */
--p-teal-900:#115E59; /*  6.89:1 on page —— 链接/已选文字 */
--p-teal-700:#0F766E; /*  5.47:1 with white —— 主按钮底 */
--p-teal-600:#0D9488; /*  4.97:1 on page —— 仅大字/图形/进度条 */
--p-teal-50: #E6F4F1; /*  选中态底色 */

/* 判定四色（语义固定，别混用） */
--p-red-700:#B42318; --p-red-800:#97231B; --p-red-50:#FBE9E7;   /* 极限词/必须改 */
--p-org-700:#B45309; --p-org-800:#9A3412; --p-org-50:#FBEBE0;   /* 待删标记/风险 */
--p-grn-700:#15803D; --p-grn-800:#166534; --p-grn-50:#E7F4EC;   /* 保留/通过 */
--p-blue-700:#1D4ED8;                                            /* 客户原话（引用） */

/* 线 */
--p-line:     #DDDAD2; /* 1.4:1 —— 纯装饰分隔线，只用于区块之间 */
--p-edge:     #6B7280; /* 4.83:1 —— 输入框/可选中卡片的边界，要能独立辨认 */
```

规则：**`--p-line` 不许当控件边界**。上一版审计里"看着有边框其实 1.4:1"的毛病，靠把装饰线和功能边界拆成两个令牌从根上堵住。

### semantic

```css
--surface-app: var(--p-page);     --surface-paper: var(--p-paper);
--surface-panel: var(--p-panel);  --surface-select: var(--p-teal-50);
--ink-primary: var(--p-ink-700);  --ink-ui: var(--p-ink-600);
--ink-muted: var(--p-ink-500);    --ink-on-action: #FFFFFF;
--action: var(--p-teal-700);      --action-text: var(--p-teal-900);
--flag-must: var(--p-red-800);    --flag-mark: var(--p-org-800);
--keep: var(--p-grn-800);         --quote: var(--p-blue-700);
--focus: var(--p-teal-700);       --edge-field: var(--p-edge);
```

组件层只允许再引语义层；**色值只出现在 primitive 一处**。

### 暗色档（"夜稿"）

`E-Ink/Paper` 明确写暗色不推荐做主档，所以暗色是第二档、跟着系统走、可锁死：

```css
[data-theme=dark] {
  --p-page:#14181B; --p-paper:#0F1315; --p-panel:#1B2124;
  --p-ink-900:#E7EAE8; /* 14.74:1 */ --p-ink-600:#A9B2B8; /* 8.29:1 */
  --p-ink-500:#8C979E; /* 5.98:1 */
  --p-teal-600:#2DD4BF; /* 9.59:1 */ --p-teal-300:#5EEAD4; /* focus ring 12.07:1 */
  --p-org-300:#F0B28C; /* 9.74:1 */ --p-grn-300:#7DD3A8; /* 9.99:1 */ --p-red-300:#F9A8A0; /* 9.47:1 */
}
```

注意层级：**纸比页面更暗**（#0F1315 < #14181B）。亮档里稿纸最亮、暗档里稿纸最暗，"稿纸永远是与环境反差最大的那一块面"这条不变，读者才永远先看到稿子。

## 4. 中文排印

零网络请求，只能用系统字体。三层分工：

```css
--font-ui:   system-ui, -apple-system, "PingFang SC", "Microsoft YaHei", "Source Han Sans SC", sans-serif;
--font-body: "Songti SC", "Source Han Serif SC", "Noto Serif CJK SC", "Noto Serif SC", STSong, SimSun, serif;
--font-num:  ui-monospace, "SF Mono", Consolas, "JetBrains Mono", monospace;
```

- **UI 用黑体，稿纸用衬线，数字用等宽**。三种字面功能不同：黑体管操作、衬线管阅读、等宽管"能不能对账"（字数、时间码、使用次数一律等宽 + `font-variant-numeric: tabular-nums`，数字跳动时不抖行）。
- Windows 上 SimSun 在小字号下会退成点阵感，所以**只有 ≥17px 的稿纸正文才允许衬线**；15px 以下的 UI 一律黑体，`--font-body` 的字号下限写死在组件层。
- 稿纸：`18px / line-height 2.0`（中文需要比西文 1.5 更宽的行距，否则上下行笔画咬字）；UI：`15px / 1.6`；标题用字重和字号拉开层级，**不靠颜色**（上一版把"弱化灰"当层级用，实测只有 2.26:1）。

字号阶（1.25 比）：`12 / 13 / 15 / 18 / 22 / 28 / 36`。`12px` 只给等宽计数与脚注，禁止用于正文句子。

## 5. 间距与尺寸

密度调钮取 7/10：`--s-1:4 --s-2:8 --s-3:12 --s-4:16 --s-5:24 --s-6:32 --s-7:48`。

命中区按 **WCAG 2.2 SC 2.5.8（Web 端 24 CSS px）**执行，不是 App 的 44px：行内「放回 / 豁免」这类小按钮做到 `28×28`（含 `::before` 扩展热区），主按钮 `40px` 高、`--s-3` 内边距，单行卡片整行可点。**被 `<label>` 包住的 radio/checkbox，命中区量 label，不量 input**——上一版审计就是量错这个报出一堆假缺陷。

## 6. 句级 diff 的视觉语言（本设计的核心）

清洗报告不该是一张表格，它就是稿纸本身。三种状态，**形状 + 颜色 + 图标三重编码**（不只靠颜色，色盲与黑白打印下仍可读）：

| 状态 | 呈现 | 落地 |
|---|---|---|
| 已删（默认采纳） | 衬线正文降为 `--p-ink-500`，整句 `line-through` 用 `text-decoration-thickness: 1px; text-decoration-color: var(--p-org-700)`，左侧 3px `--p-org-50` 色条 | hover/focus 时行尾浮出「放回」 |
| 放回后（保留） | 恢复正常墨色，左侧 3px `--p-grn-50`，行尾一个 `已放回` 小 pill | 可撤销 |
| 只标记【待删】 | 底色 `--p-org-50`，前缀一个方括号符号，不划线（因为还没决定） | 行尾「删整句 / 留着」 |
| 极限词 | 词级 `underline wavy var(--p-red-700)`，配 `⚠` 形状符号 | 点击跳到检视器对应风险条目 |

时间码一律 `--font-num`、`--p-ink-500`，与正文之间用 `--s-2` 空格，**不参与行高**。

## 7. 动效

`--motion 3/10`（Subtle）。工作台不做编排：

- 只允许 `background-color / color / border-color / opacity / transform`；**禁止动 `width/height`**（会顶动稿纸行位置，读者刚要看的那句会跳）。
- 时长：状态反馈 120ms，面板进出 200ms，`ease-out` 进 / `ease-in` 出（出比进场快）。
- `prefers-reduced-motion: reduce` 时全部降到 0ms 且终态立刻到位。
- 全站**只有一个 live region**（`#toast`，`role=status aria-live=polite`）。步骤计数、风险计数这类变化不要各自挂 `aria-live`，否则读屏会被抢话——这条是上一轮已经踩过的坑。

## 8. 组件规范（摘要）

- **按钮四档**：`primary`（青底白字，一个屏内最多一个）、`secondary`（白底 `--p-edge` 边、青字）、`ghost`（无边、青字）、`danger-quiet`（灰字，按下才变红）。禁止再出现"绿底白字 pill"这种 2.62:1 的组合。
- **pill / 计数徽章**：浅色底 + 800 档文字（实测 6.28–6.96:1），不用饱和底白字。
- **空状态**：说下一步做什么，不是"暂无数据"。例：素材库空 → "清洗过的句子会自动进这里。先粘一段稿子试试。" 并给一个真的能点的「载入示例稿」。
- **危险操作**：清空全部数据、清空库存——二级确认用内联展开（点一下变成"确认清空？是 / 否"），不弹 `confirm()`。

## 10. 明确不做

- 不做营销落地页式 hero、不做插画、不做渐变背景。
- 不做多主题皮肤市场——只有"日稿/夜稿"两档。
- 不动逻辑层：新 UI 只换 DOM 结构与样式，`core` 脚本块与 80 条页内自检必须原样通过。
