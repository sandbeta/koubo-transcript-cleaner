# 口播文字稿整理工具

把一段啰嗦的口播转写稿，整理成可以直接开剪的脚本。单文件 HTML，双击即用，不需要安装、不需要网络。

面向**「我 vs 客户」故事型口播**（实体店 / 服务行业的老板 IP 内容）。

## 它解决什么

语音转文字出来的稿子通常是几千字的口水话：寒暄、磕巴、"嗯那个就是说"、同一个意思讲三遍。
传统做法是手工删改一遍再喂给大模型，而大模型又会把你没说的东西编出来。

这个工具把过程拆成两段，各让擅长的一方做：

1. **本地做确定性的删减**（去语气词、合并重复、删寒暄、按黑名单删整句），每一刀都留痕、可逐条撤回；
2. **大模型做需要判断的取舍**（哪些片段值得留、怎么排叙事），但被明确要求"不许添加文稿里没有的事实、数字、案例"。

## 用法

```
① 三要素标准  定义哪些片段必须留下（人设 / 转化 / 流量）
② 黑名单      定义哪些内容自动删（寒暄 / 自我介绍 / 数据铺垫 …）
③ 粘稿 → 预清洗   本地清洗，出清洗报告 + 合规风险 + 故事结构 + 素材体检
④ 素材库      把可用的零件攒下来，按故事零件分桶，记录用过几次、表现如何
⑤ 成片记录    下载终稿时自动登记，发布后回填一次评分
```

然后把右侧生成的 **Prompt 包**复制给任意大模型，把它返回的 Markdown 粘回"最终整理稿"，复制或下载 `.md` 交给剪辑。

想先看看效果：把文件里的 `koubo-transcript-cleaner.html` 打开，在地址后加 `?demo=1`（或点"载入示例稿"）。

## 值得一提的几处设计

- **清洗可核对**：句子级删除逐条给出"放回"按钮。放回不是改文本，而是把该句加进豁免表后整体重算，避免位置漂移。
- **合规风险只标不删**：绝对化用语、效果承诺、功效暗示等 6 类，命中后给改口建议，并自动写进 Prompt 让模型改写时避开。误报防护做了（`第一次` 不会命中 `第一`，`胃里舒服` 不会命中 `养胃`）。
- **故事结构按段检测**：一篇稿子讲两个客户故事时，整篇合看"零件齐"是假绿灯——一段缺的证据不能被另一段补上，所以按空行或时间码大跳分段逐段查。
- **判重不只看字形**：口播里"上个月有个客户…"这类套路开头会被相似度算法误判成重复。真正区分靠"去掉虚词后的实词重合度"。
- **战绩只有一个真相源**：素材用过几次由成片记录反查得出（含大模型改写过的句子），不维护第二份计数器。

## 数据与隐私

全部数据存在你这台电脑的 `localStorage` 里，页面不发起任何网络请求，没有埋点、没有后端。
换电脑或重装浏览器前用页脚的「导出完整备份」（导入是**合并**而非覆盖，且会重映射素材 id，战绩链不会断）。

## 自检与开发

页面内置端到端自检，改完东西跑一下：

```js
kouboSelftest()        // 控制台执行，或地址加 ?selftest=1 —— 80 项 DOM 级断言
```

Node 侧（纯逻辑层，不需要浏览器）：

```bash
node test-core.js   # 清洗规则与误伤回归
node test-v3.js     # 极限词 / 故事零件 / 判重 / 放回豁免
node test-v4.js     # 成片登记、素材↔成片匹配、段落分隔
node test-v5.js     # 备份合并与 id 重映射、配额降级
node check-html.js  # 结构自检：id 唯一、按钮是否都有处理函数、标签配平
```

| 文件 | 作用 |
| --- | --- |
| `koubo-transcript-cleaner.html` | 工具本体（内含核心逻辑层 / UI 层 / 自检层三段脚本） |
| `index.html` | 跳转页，让仓库根路径也能打开 |
| `test-*.js` | Node 逻辑回归，共 132 条断言（28 + 45 + 36 + 23） |
| `check-html.js` / `extract.js` / `audit.html` | 结构检查与 UI 审计台 |
| `ui-redesign/README-皮肤.md` | 星露谷皮肤怎么改、静态门禁跑哪些（皮肤块就在工具本体的 `<head>` 里） |

## 明确不做

内置语音转文字（打不过剪映/讯飞且要花钱）、直连大模型出终稿（会把输出质量责任揽到自己身上）、账号与协作。
